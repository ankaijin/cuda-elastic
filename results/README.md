# CUDA performance results

GPU: NVIDIA GeForce RTX 3090 (sm_86, 24 GB). Times in microseconds (lower is better). Latest run of each workload's current implementation at the largest problem size tested (dominant kernel, if one dominates, and the whole application), generated by `build_spreadsheet.py` from profiles committed in this repo. The spreadsheet [`cuda_performance.xlsx`](cuda_performance.xlsx) also has the ncu metrics of every profiled launch.

**Direct** = the same kernels launched without a CUDA Graph (only llama2c has this mode; the other harnesses are graph-only). — = not available.

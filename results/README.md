# CUDA performance results

GPU: NVIDIA GeForce RTX 3090 (sm_86, 24 GB). Times in microseconds (lower is better). Generated by `build_spreadsheet.py` from profiles already committed in this repo; the full table with per-cell ncu-rep / nsys sqlite links, value sources, every ncu metric and the launch sweeps is [`cuda_performance.xlsx`](cuda_performance.xlsx).

Columns: **Baseline** = naive kernels, direct launches; **CUDA Graph** = the same kernels as a CUDA Graph; **Optimized** = our optimized kernels (graph-launched); **SOTA** = library reference (none measured yet). — = not measured.

GPU-metrics nsys traces are committed as `.sqlite.zst` because the `.sqlite` exceeds GitHub's 100 MB limit; restore with `zstd -d <file>.sqlite.zst`.

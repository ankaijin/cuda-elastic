# Private Loom CUDA workloads: results v1

Generated by `results/loom_private/build_report.py` from the records selected in `results/loom_private/inputs/<gpu>.json`. This page is separate from the legacy [results](../README.md); the legacy workloads and their measurements are unchanged.
